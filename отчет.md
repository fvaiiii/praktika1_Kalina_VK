# Отчёт по практической №1 — Вариант 4 (Q16)

## 1. Вариант и масштаб

| Поле | Значение |
|---|---|
| ФИО (как в VK Education) | **Калина Дарья Романовна** |
| Вариант (запрос) | **Q16 (Parts/Supplier Relationship)** |
| Масштаб `sfN` | **sf1** |
| Почему выбрал такой масштаб | Оптимальный объём данных (таблицы до 800 тыс. строк) для полной локальной проверки в Docker без перегрузки CPU и RAM. |

---

## 2. Поднятые сервисы — и почему именно они

| Сервис | Роль в стеке | Почему именно он (а не альтернатива) |
|---|---|---|
| **MinIO** | S3-совместимое объектное хранилище (сюда физически падают parquet-файлы) | Открытое и легковесное S3-хранилище; хранит Parquet-файлы с разделением по бакетам/префиксам вархаусов (`bronze/`, `silver/`, `gold/`, `bench/`). |
| **PostgreSQL 17** | БД, где Lakekeeper хранит метаданные каталога | Надежная реляционная БД для хранения состояний, конфигураций вархаусов и проекций REST-каталога. |
| **Lakekeeper** | Iceberg REST Catalog — каталог метаданных таблиц | Современный декларативный REST-каталог для Apache Iceberg; поддерживает разделение на изолированные вархаусы и заменяет тяжеловесный Hive Metastore. |
| **Trino 476** | SQL-движок: ходит в Lakekeeper за метаданными и читает/пишет данные в MinIO | Высокопроизводительный распределенный SQL-движок с нативной поддержкой Iceberg REST Catalog и параллельной обработкой Parquet. |
| **Apache Spark** | Движок / клиент для работы с Lakehouse | Внешний инструмент обработок, интегрированный через `spark/conf/spark-defaults.conf` с REST-каталогом Lakekeeper. |

### Скрипты, которыми поднимал стек

```bash
# 1. MinIO — объектное хранилище S3
docker run -d --name lakehouse-minio \
  -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=minioadmin \
  -e MINIO_ROOT_PASSWORD=minioadmin \
  -v minio-data:/data \
  cgr.dev/chainguard/minio server /data --console-address ":9001"

# 2. PostgreSQL — база метаданных для Lakekeeper
docker run -d --name lakehouse-pg \
  -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 \
  -v pg-data:/var/lib/postgresql/data \
  postgres:17

# 3. Lakekeeper — Iceberg REST Catalog
docker run -d --name lakekeeper \
  -e 'LAKEKEEPER__PG_ENCRYPTION_KEY=This-is-NOT-Secure!' \
  -e 'LAKEKEEPER__PG_DATABASE_URL_READ=postgresql://postgres:postgres@host.docker.internal:5432/postgres' \
  -e 'LAKEKEEPER__PG_DATABASE_URL_WRITE=postgresql://postgres:postgres@host.docker.internal:5432/postgres' \
  -p 8181:8181 \
  quay.io/lakekeeper/catalog:latest-main serve

# 4. Trino — SQL-движок
docker run -d --name trino \
  -p 8080:8080 \
  -v "$(pwd)/catalog:/etc/trino/catalog" \
  trinodb/trino:476
